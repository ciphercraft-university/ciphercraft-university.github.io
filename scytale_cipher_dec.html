HOW DECRYPTION WORKS

Decryption reverses the encryption process to recover the original message:

  1. Create Grid: Generate an empty grid with the key as the number of columns. Calculate rows based on ciphertext length.
  2. Fill Grid Column-by-Column: Write the ciphertext into the grid by filling each column from top to bottom, left to right.
  3. Read Grid Row-by-Row: Read the grid normally from left to right, row by row to recover the plaintext.

This process effectively "unwraps" the ciphertext from the imaginary rod, reversing the transposition that occurred during encryption.

Example: If encryption transformed "ATTACKATDAWN" to "ACDTKATAWATN" with key=4, decryption will reverse this process.
