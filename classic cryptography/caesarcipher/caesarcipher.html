HOW CAESAR CIPHER WORKS

ENCRYPTION ALGORITHM

  • Substitution Cipher: Each letter is replaced by another letter
  • Fixed Shift: All letters shift by the same amount (key)
  • Modular Arithmetic: Wrap-around using modulo 26
  • Formula: Eₖ(m) = (m + k) mod 26
  • Decryption: Dₖ(c) = (c - k) mod 26
