STEP-BY-STEP PROCESS

1
UNDERSTAND THE EQUATION
We need to express:
dividend = divisor × quotient + remainder
For −3 ÷ 26:
−3 = 26 × q + r, where 0 ≤ r < 26
2
FIND THE QUOTIENT
Calculate using floor division:
q = floor(−3 / 26) q = floor(−0.115...) q = −1
Round down to nearest integer.
3
CALCULATE REMAINDER
Apply the formula:
r = −3 - (26 × −1) r = −3 + 26 r = 23
Satisfies: 0 ≤ 23 < 26

MATHEMATICAL DEFINITION

For any integers a and n > 0, the modulo operation is defined as:

a mod n = a - n × floor(a / n)

Applied to our example:

−3 mod 26 = −3 - 26 × floor(−3 / 26) = −3 - 26 × (−1) = −3 + 26 = 23

This definition ensures the remainder is always non-negative and less than the divisor.
