The Caesar Cipher

A deep dive into history's most famous substitution cipher and its mathematical foundations.

1. Introduction

The Caesar cipher is one of the simplest and most well-known encryption techniques. Named after Julius Caesar, who used it in his private correspondence, it's a type of substitution cipher where each letter in the plaintext is shifted a certain number of places down the alphabet.

Core Principle

Unlike transposition ciphers that rearrange letters, the Caesar cipher substitutes each letter with another letter a fixed number of positions away. This makes it a monoalphabetic substitution cipher.

1.1 Historical Context

Julius Caesar used a shift of 3 (A→D, B→E, ..., Z→C) for his military communications. While incredibly simple by modern standards, it provided adequate security against illiterate enemies and casual observers.

2. Mathematical Foundation

The elegance of Caesar cipher lies in its mathematical formulation using modular arithmetic.

mathematical_notation.conf
Let: A = 0, B = 1, C = 2, ..., Z = 25 ENCRYPTION: Eₖ(m) = (m + k) mod 26 DECRYPTION: Dₖ(c) = (c - k) mod 26 Where: m = plaintext letter's numeric value c = ciphertext letter's numeric value k = key (shift amount) mod 26 = wrap-around operation

2.1 Modular Arithmetic in Action

Consider encrypting 'Y' with shift 3:

  • Y = 24 (numerical value)
  • 24 + 3 = 27
  • 27 mod 26 = 1
  • 1 = B
  • Thus, Y → B (wrap-around achieved)

Negative Modulo Insight

Decryption often involves negative numbers. In modular arithmetic: -2 mod 26 = 24. This is because we're dealing with a circular number system, not traditional division.

3. Python Implementation

A complete implementation with encryption and decryption functions.

caesar.py 
def caesar_encrypt(plaintext, key):
    # Convert to uppercase and process
    cipher_text = ''
    plaintext = plaintext.upper()
    
    for char in plaintext:
        if char == ' ':
            cipher_text += ' '
        elif char.isalpha():
            # Convert letter to number (A=0, B=1, ...)
            index = ord(char) - ord('A')
            # Apply shift with wrap-around
            index = (index + key) % 26
            # Convert back to letter
            cipher_text += chr(index + ord('A'))
        else:
            cipher_text += char
    
    return cipher_text

def caesar_decrypt(ciphertext, key):
    # Decryption is just encryption with negative key
    plain_text = ''
    ciphertext = ciphertext.upper()
    
    for char in ciphertext:
        if char == ' ':
            plain_text += ' '
        elif char.isalpha():
            index = ord(char) - ord('A')
            # Apply reverse shift with wrap-around
            index = (index - key) % 26
            plain_text += chr(index + ord('A'))
        else:
            plain_text += char
    
    return plain_text

4. Cryptanalysis & Weaknesses

Security Assessment: TRIVIAL TO BREAK

The Caesar cipher provides no semantic security and can be broken with minimal effort.

4.1 Attack Methods

  • Brute Force Attack: Only 25 possible keys (excluding shift of 0). A computer can test all possibilities in microseconds.
  • Frequency Analysis: The most common letter in English is 'E'. Find the most common ciphertext letter and assume it decrypts to 'E'.
  • Known Plaintext Attack: If you know any word in the message, you can immediately deduce the key.

4.2 Automated Cracker
